## 2. Work Items

### WI-1: Forward --task-id in build_surface_command() (PR #771 bot finding P1)

**Finding:** `build_surface_command()` at `executor_dispatch.py:266-282` builds
the Phase B command without forwarding `--task-id`. `phase_b_executor.py` already
accepts `--task-id` (verified in PR #771 bot report), but the dispatcher does not
pass it through for direct Phase B launches.

**Fix:** Add `if getattr(args, 'task_id', ''): cmd.extend(['--task-id', args.task_id])`
at the end of `build_surface_command()`.

**Acceptance:** `build_surface_command()` output includes `--task-id` when
`args.task_id` is non-empty. Unit test verifies this.

### WI-2: Sort learning.md entries newest-first (PR #771 bot finding P2)

**Finding:** `_load_learning_md_entries()` in `recovery_gate.py` reads entries
top-to-bottom. Manually curated entries at the top are correctly ordered
(newest-first), but promoted entries appended at EOF by `_export_to_learning_md()`
would be consumed last and potentially truncated under the 4000-char budget.

**Fix:** Sort entries by date descending in the return value of
`_load_learning_md_entries()`, or reverse the list before consumption in
`load_relevant_learnings()`.

**Acceptance:** `load_relevant_learnings()` returns entries sorted by date
descending regardless of file ordering.

### WI-3: Triage deferred findings from PRs #760-761 and #769

**PR #769 findings:** Both P1 (repo-relative artifact paths in
`artifact-edit-gate.sh`) and P2 (descendant snapshot guard in
`executor_dispatch.py`) are documented false positives with empirical evidence in
`reports/deferred/non_blocking/pr769_bot_findings_2026-04-13.md`. Verify
documentation is complete and close — no code change needed.

**PR #760 finding:** Review `pr760_late_bot_p1_2026-04-12.md`, reclassify or fix.

**PR #761 finding:** `force-mcp-sqlite` hook is now tracked via PR #769. Verify
resolved and update deferred file status.

**Acceptance:** All deferred findings reviewed — each is either fixed,
reclassified, or re-deferred with current evidence.
